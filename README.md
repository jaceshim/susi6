# 수시 경쟁률 현황 (2027학년도)

관심 모집단위의 수시 경쟁률을 **퍼팩(PERFACT) 입시허브 공개 API 로 실시간 조회**하고,
2027 / 2026 학년도를 나란히 비교하는 정적 웹페이지입니다.

수집 서버도, 주기적 스크레이핑도 없습니다. 화면의 값은 페이지가 방금 API 에서 받은 값입니다.

## 어떻게 동작하나

```
브라우저 ──► api.prft.co.kr (CORS 허용)
   live-meta    실시간 제공 대학 173곳 + 대학별 접수 마감시각 + 원본 링크 + 기준시각   (진입 시 1회)
   admissions   대학의 전형 목록                                                     (대학 고를 때)
   departments  전형의 학과 목록                                                     (전형 고를 때)
   lookup       모집단위 하나의 모집인원 · 경쟁률 · D-3/D-2/D-1                       (카드마다, 2027+2026)
```

이전 버전은 진학사·유웨이 경쟁률 페이지를 GitHub Actions 에서 긁었는데, 진학사 계열이 러너 IP 를
차단해 85개교가 비었습니다. 이 API 는 같은 원본을 이미 정규화해 제공하고 CORS 가 열려 있어
브라우저에서 바로 부를 수 있습니다. 그래서 수집기·차단 우회·쿠키 캐시가 전부 필요 없어졌습니다.

## 필요한 파일

**`index.html` 하나면 됩니다.** HTML·CSS·JavaScript 가 모두 그 안에 들어 있고,
서버·빌드·설치·파이썬 모두 필요 없습니다. 파일을 더블클릭해 브라우저로 열어도 동작합니다
(로컬 파일의 `Origin: null` 에서도 API 가 응답하는 것을 확인했습니다).

아래는 전부 **선택 사항**입니다.

```
index.html                        ← 이것만 있으면 동작 (단일 파일, 약 55KB)
data/catalog.json                 대학 목록 스냅샷 (선택)
data/cat/<대학id>.json            전형·학과 트리 스냅샷 (선택, --full 로 만들 때만)
scripts/build-catalog.mjs         위 스냅샷 생성기 (Node, 선택)
.github/workflows/catalog.yml     매일 05:00 KST 스냅샷 갱신 (선택)
```

스냅샷이 없으면 페이지가 진입할 때 `live-meta` 를 불러 대학 목록을 채웁니다(호출 1회).
있으면 선택 UI 가 API 응답을 기다리지 않고 바로 뜨고, 353개교(실시간 173 + 그 외) 전체가 검색됩니다.
경쟁률은 어느 경우든 실행 중 API 로 직접 조회하므로 스냅샷과 무관하게 항상 최신입니다.

```bash
node scripts/build-catalog.mjs .          # 대학 목록만 (호출 3번, 수초)
node scripts/build-catalog.mjs . --full   # 전형·학과 트리까지 (대학당 1+N 호출, 수분)
```

## 화면

- **선택한 대학의 경쟁률** — 모집단위별 카드. 실시간 경쟁률, 직전 D단계 대비 변화, 모집인원,
  지원(환산) 인원, 원본 기준시각, 추이 스파크라인, 원본 페이지 링크.
- **2027 · 2026 비교** — 모집단위 하나가 두 줄. 대학·모집단위와 실시간 경쟁률(올해만)은
  두 줄에 걸쳐 한 번만 표시하고, 학년도별로 **모집인원 · D-3 · D-2 · D-1** 을 나란히 놓습니다.
  올해 값이 지난해보다 높으면 붉게, 낮으면 초록으로 표시합니다.
- 대학 검색은 초성으로도 됩니다 (`ㄱㅎ` → 경희대학교). 실시간 대상이 아닌 대학도 목록에 보이며
  고르면 사유를 알려줍니다.

## 숫자에 대해

- **실시간 경쟁률** = API 의 `rate_final` (최신값). **D-3 / D-2 / D-1** = 원서접수 단계별 값.
- **지원(환산) 인원** = 경쟁률 × 모집인원. API 가 지원자 수를 따로 주지 않아 환산한 값이라
  실제와 1~2명 차이가 날 수 있습니다.
- **접수 마감**은 API 가 대학별로 준 정확한 시각을 씁니다(대학에 따라 17:00~23:59 로 다릅니다).
- 카드의 스파크라인은 D단계 값 + **이 브라우저가 본 값**으로 그립니다. 브라우저에만 쌓이므로
  다른 기기에서는 D단계 값만 보입니다.
- 지난해에 없던 모집단위는 비교표에서 `—` 로 표시됩니다. 대학명·전형명이 해가 바뀌며 달라진
  경우에도 `—` 가 될 수 있습니다.

## 쓰는 방법

가장 간단한 순서대로:

1. **그냥 열기** — `index.html` 을 브라우저로 엽니다. 끝.
2. **휴대폰에서도 보려면** — 정적 호스팅에 `index.html` 을 올립니다. GitHub Pages 라면
   저장소에 push 하고 `Settings → Pages` → Source **Deploy from a branch**, Branch **main / (root)**.
3. **선택 UI 를 더 빠르게** — `Settings → Actions → General → Workflow permissions` 를
   **Read and write** 로 두고 `Actions → 대학·전형·학과 목록 갱신 → Run workflow` 를 한 번 실행하면
   목록 스냅샷이 커밋됩니다.

선택 목록과 추이는 브라우저 `localStorage` 에만 저장되어 기기 간에 공유되지 않습니다.
로컬 파일로 열 때는 `data/catalog.json` 을 읽지 못해 스냅샷 없이 동작합니다(기능 차이는 없습니다).

## 주의

경쟁률은 원서접수 진행 중 계속 바뀌고, 마감 직전 몇 시간에 가장 크게 움직입니다.
**마감 시각과 최종 경쟁률은 반드시 각 대학 입학처 공고로 확인하세요.**
이 페이지는 제3자 API 를 조회하는 도구이며, 값의 정확성은 원본과 API 에 달려 있습니다.
